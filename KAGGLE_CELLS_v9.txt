RECAP FREE — KAGGLE RUN CELLS v12
=================================

ဒီ cells တွေက production GitHub main နဲ့ကိုက်ပါတယ်။ API key ကို code ထဲမထည့်ပါ။ Cloud AI သုံးမှသာ UI Settings ထဲမှာ session အတွင်း ထည့်ပါ။

အရေးကြီးသော defaults:
- Edge TTS: တစ်ပြိုင်တည်း အများဆုံး ၃ jobs
- VoxCPM2: တစ်ပြိုင်တည်း အများဆုံး ၁ job
- Local Whisper + Local NLLB: Cell 3 မှာ UI မဖွင့်ခင် download လုပ်မည်
- VoxCPM HIFI continuation: default ပိတ်ထားသည်။ Reference audio မကိုက်လို့ ကွိကွိအသံ မထွက်အောင် timbre-only clone ကို default သုံးမည်
- Output resolution: video ပြီးမှ Download 1080p / 2K / 4K ရွေးမည်
- History: Queue အောက်မှာ ပြီးဆုံးထားသော videos အဖြစ် စာရင်းပြမည်

CELL 4 — DOWNLOAD LOCAL MODELS BEFORE UI
----------------------------------------
```python
%cd /kaggle/working/recap-free

import os
from pathlib import Path
from huggingface_hub import snapshot_download

models_root = Path('/kaggle/working/models')
models_root.mkdir(parents=True, exist_ok=True)

voxcpm_dir = models_root / 'VoxCPM2'
whisper_dir = models_root / 'faster-whisper-large-v3'
nllb_dir = models_root / 'nllb-200-distilled-1.3B'

print('Downloading VoxCPM2...')
snapshot_download(
    repo_id='openbmb/VoxCPM2',
    local_dir=str(voxcpm_dir),
)

print('Downloading Faster-Whisper...')
snapshot_download(
    repo_id='Systran/faster-whisper-large-v3',
    local_dir=str(whisper_dir),
)

print('Downloading NLLB-200...')
snapshot_download(
    repo_id='facebook/nllb-200-distilled-1.3B',
    local_dir=str(nllb_dir),
)

# These variables must be set in the same notebook session before starting the server.
os.environ['VOXCPM_MODEL_ID'] = str(voxcpm_dir)
os.environ['RECAP_WHISPER_MODEL'] = str(whisper_dir)
os.environ['RECAP_NLLB_MODEL'] = str(nllb_dir)
os.environ['HF_HOME'] = '/kaggle/working/huggingface'
os.environ['RECAP_LOCAL_ONLY'] = '1'

# T4 GPU assignment.
os.environ['RECAP_WHISPER_DEVICE'] = 'cuda'
os.environ['RECAP_WHISPER_DEVICE_INDEX'] = '0'
os.environ['RECAP_WHISPER_COMPUTE'] = 'float16'
os.environ['RECAP_NLLB_DEVICE'] = 'cuda:1' if __import__('torch').cuda.device_count() >= 2 else 'cuda:0'
os.environ['RECAP_TRANSLATION_BATCH'] = '4'
os.environ['RECAP_NLLB_BEAMS'] = '5'

# Stable VoxCPM voice cloning: use uploaded reference timbre only by default.
# Set this to 1 only when the reference text exactly matches the audio word-for-word.
os.environ['RECAP_VOXCPM_HIFI'] = '0'
os.environ['RECAP_VOXCPM_CFG'] = '2.0'
os.environ['RECAP_VOXCPM_STEPS'] = '10'

print('VoxCPM2:', voxcpm_dir)
print('Whisper:', whisper_dir)
print('NLLB:', nllb_dir)
print('NLLB device:', os.environ['RECAP_NLLB_DEVICE'])
print('VoxCPM HIFI:', os.environ['RECAP_VOXCPM_HIFI'])
print('All local models are ready.')
```

Cell 5 output ထဲက နောက်ဆုံး `https://....trycloudflare.com` URL ကို browser မှာ ဖွင့်ပါ။ Tunnel URL ပျက်သွားရင် ဒီ Cell ကို မရပ်ပါနှင့်။ Supervisor က URL အသစ်ထုတ်ပါမည်။

UI အသုံးပြုပုံ
--------------
1. Local AI သုံးမယ်ဆို Settings → AI Mode → `Local AI` ထားပါ။ API key မလိုပါ။
2. Edge TTS သုံးမယ်ဆို Voice Engine → `Edge TTS` ရွေးပါ။
3. VoxCPM2 သုံးမယ်ဆို Voice Engine → `VoxCPM2` ရွေးပြီး Reference Text ကို audio ထဲက စာသားအတိုင်းထည့်ပါ။ ပြီးမှ audio upload လုပ်ပါ။
4. VoxCPM2 က reference audio မရွေးဘဲ run လုပ်ရင် random voice မသုံးတော့ဘဲ error ပြပါမည်။
5. Auto Blur ကိုဖွင့်/ပိတ်နိုင်ပါသည်။ UI မှာ internal detection flow မပြပါ။
6. Final video ပြီးမှ completed view ထဲက `Download 1080p`, `Download 2K`, `Download 4K` ရွေးပြီး `Video Download` နှိပ်ပါ။
7. ပြီးဆုံးထားသော videos များကို Queue အောက်က History list မှာ တန်းစီပြပါမည်။

RECOVERY CELL — DEAD URL / DNS ERROR
-------------------------------------
```python
import os
import signal
import subprocess
import sys
import time
from pathlib import Path

root = Path('/kaggle/working/recap-free')
os.chdir(root)

# Stop only this project's old server and cloudflared processes.
subprocess.run("pkill -f 'cloudflared.*127.0.0.1:8000'", shell=True, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
subprocess.run("pkill -f 'python.*kaggle_foreground.py'", shell=True, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
subprocess.run("pkill -f 'python.*run.py'", shell=True, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
time.sleep(2)

log_dir = root / 'logs'
log_dir.mkdir(exist_ok=True)
log = (log_dir / 'supervisor_notebook.log').open('ab')
proc = subprocess.Popen(
    [sys.executable, 'kaggle_foreground.py'],
    cwd=root, stdout=log, stderr=subprocess.STDOUT,
    stdin=subprocess.DEVNULL, start_new_session=True,
)
print('Supervisor PID:', proc.pid)
print('စက္ကန့်အနည်းငယ်စောင့်ပြီး Recovery Cell 2 ကို run ပါ။')
```

RECOVERY CELL 2 — READ THE LATEST URL
-------------------------------------
```python
from pathlib import Path
import re
import time

log_path = Path('/kaggle/working/recap-free/logs/supervisor_notebook.log')
for _ in range(20):
    if log_path.exists():
        text = log_path.read_text(errors='ignore')
        urls = re.findall(r'https://[a-zA-Z0-9-]+\.trycloudflare\.com', text)
        if urls:
            print('CURRENT PUBLIC URL:', urls[-1])
            break
    time.sleep(2)
else:
    print('URL မထွက်သေးပါ။ Log နောက်ဆုံးပိုင်း:')
    print(log_path.read_text(errors='ignore')[-4000:] if log_path.exists() else 'log မရှိသေးပါ')
```

အဟောင်း URL ကို မသုံးပါနှင့်။ `CURRENT PUBLIC URL` နောက်ဆုံးထွက်တဲ့ URL ကိုသာ ဖွင့်ပါ။
